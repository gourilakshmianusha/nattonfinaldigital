# Natton Digital immersive hero concept

The current application uses these free, open-source libraries:

- React and React DOM — MIT, https://github.com/facebook/react
- Vite — MIT, https://github.com/vitejs/vite
- Manrope font — SIL Open Font License, https://github.com/sharanda/manrope

The original 3D environment is authored and rendered with Blender through the official Blender Foundation `bpy` package (Blender software: GPL-3.0-or-later). Pillow (HPND) converts the generated images to WebP. The Blender software licence does not require its original rendered images to be GPL-licensed. No Blender executable or Python module is shipped to visitors.

All scene geometry, materials, camera paths, animated assemblies and render frames were created for this concept. The sequence is drawn on HTML Canvas 2D and follows the visitor's scroll position; it does not depend on WebGL. No purchased 3D models, templates, HDR environments or premium assets are required. Natton's logo belongs to Natton Digital.

The repository also retains dependencies used by earlier real-time prototypes: Three.js (MIT), React Three Fiber (MIT), Drei (MIT), React Three Postprocessing (MIT) and Postprocessing (Zlib). These are not imported by the current entrypoint and are excluded from its production JavaScript bundle.

GrowthOS, AI Marketing Platform, BusinessOS and AgenticOS describe tailored engagements rather than establishing that self-service software subscriptions are available today. The contact interaction opens an email client; it does not submit data to a backend.
