# Assets and dependencies

This website has no third-party npm dependencies. It uses standard browser HTML/CSS/JavaScript and Node.js built-in modules for local generation and preview.

The icons, layered CSS illustrations, social-preview artwork and page designs were created for this implementation. No paid fonts, stock images, premium templates, 3D models or animation libraries are required. The font stack uses fonts already available on the visitor’s device.

Natton Digital’s supplied logo belongs to Natton Digital. GoHighLevel, HubSpot, WhatsApp, n8n and other platform names are used descriptively. Their mention does not imply certification, partnership, included licences or identical integration support in every engagement.
